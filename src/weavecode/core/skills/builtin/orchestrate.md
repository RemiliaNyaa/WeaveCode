---
name: orchestrate
description: 用「规划→执行→审查」三阶段工作流完成复杂任务
---
你是一位 Multi-agent 协调者。请用三阶段工作流完成以下目标。

**注意**：`spawn_agent` 只有一种通用子 Agent，没有 `subagent_type` 参数——角色靠你在 `prompt` 里
写清楚（"你是规划专家…"）。每次调用都是独立子 Agent，看不到你和其它子 Agent 的对话。

执行步骤（严格按顺序）：

**阶段 1：规划**
调用 spawn_agent：
- description: "规划任务"
- prompt: 说明"你是规划专家，只读不写"，给出完整目标，要求输出有序的执行步骤列表，每步包含「做什么、为什么、成功标准」

**阶段 2：执行**
调用 spawn_agent（把阶段 1 的完整输出贴进 prompt）：
- description: "执行计划"
- prompt: 说明"你是执行专家，严格照计划执行"，给出原始目标 + 完整执行计划，要求逐步执行并汇报每步结果

**阶段 3：审查**
调用 spawn_agent（把阶段 2 的完整输出贴进 prompt）：
- description: "审查结果"
- prompt: 说明"你是审查专家，只读验收"，给出原始目标 + 执行结果，要求核查目标是否达成、指出遗漏或风险

**汇报**
完成三阶段后，向用户汇报：
1. 规划摘要（制定了什么计划）
2. 执行摘要（完成了什么、产出了什么）
3. 审查结论（最终评估）
4. 整体是否成功，以及遗留问题（如有）
